## Contexte

L'outil est public et open source : un résultat n'a de valeur dans un débat que si n'importe qui peut le vérifier. Décision prise : **AGPL-3.0** pour le code, **Licence Ouverte 2.0 (Etalab)** pour les données dérivées. La méthodologie est publiée avec l'outil ; toute version déployée et modifiée doit publier ses modifications (transparence n° 6).

## Objectif

Mettre en place les licences et le document de méthodologie.

## Tâches

- [ ] `LICENSE` AGPL-3.0 à la racine du code (`budget-analyser/`).
- [ ] Licence Ouverte 2.0 appliquée au dépôt de données / données dérivées.
- [ ] En-têtes/README précisant le périmètre de chaque licence.
- [ ] Document de méthodologie publié (formules, hypothèses, choix de sources), lié depuis la fiche.
- [ ] Mention de l'obligation AGPL de publier les modifications d'une version déployée.

## Critères d'acceptation

- Code et données portent chacun la bonne licence.
- La méthodologie est accessible publiquement et référencée par l'outil.
